# 线虫摆动频率分析系统

把线虫视频交给它，自动统计每只线虫的头部摆动次数与频率。

## 启动（只做一次安装）

1. 安装 Python 3.10 以上版本，安装时勾选 `Add python.exe to PATH`
2. 双击 `1-安装依赖.bat`，等它自动装完（约 5~15 分钟，需要联网）
3. 双击 `2-启动.bat`，浏览器会自动打开 <http://127.0.0.1:5000>

以后再使用，只需要第 3 步。

## 使用

1. 在网页里上传一个线虫视频
2. 等它处理：画面上每个编号都会显示摆动次数与实时频率
3. 处理完成后下载结果视频、子视频或摆动汇总 CSV

## 须知

- 处理结果在 `backend\data\results\`，上传的原视频在 `backend\data\uploads\`
- 关闭启动时打开的命令行窗口，程序即停止
- 不需要显卡，不需要 Node.js
- 觉得处理慢：启动前执行 `set INFER_IMGSZ=640` 再启动（速度约快 3 倍，但更容易丢帧）
- 想用自己的数据训练模型：见 `backend\docs\技术说明.md`（需要 NVIDIA 显卡）
- 想用 GPU 加速识别：运行 `4-安装GPU训练依赖.bat`，重启后自动使用 GPU

## 遇到问题

| 现象 | 处理 |
| --- | --- |
| 提示找不到 Python | 重装并勾选 `Add python.exe to PATH` |
| pip 下载慢 | 命令后加 `-i https://pypi.tuna.tsinghua.edu.cn/simple` |
| 5000 端口被占用 | 先执行 `set PORT=5001` 再启动 |
| 页面打不开 | 首次启动要加载模型，等 10~30 秒后刷新 |

完整说明：`backend\docs\使用说明.md`（使用与调优）、`backend\docs\技术说明.md`（算法与训练）。
